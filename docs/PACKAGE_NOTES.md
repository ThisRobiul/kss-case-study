# Files and presentation status

This repository is a public **design case study**, not the production source code.

- `README.md` — primary case study shown on the repository homepage.
- `index.html` — interactive image gallery for GitHub Pages.
- `assets/` — gallery CSS/JS and case-study cover images.
- `screens/` — 34 curated screenshots grouped by product surface.
- `prototypes/` — editable HTML/CSS/JavaScript presentation-only screens.
- `docs/` — screen index, upload instructions, original design production notes, and manifest.

The reference product includes a real Android app, public web experience, central admin panel, and doctor/hospital/staff administrative panel. The image collection contains redesigned or illustrative presentations of these product surfaces. **UI concepts and sample values are not verified production results.**

No backend code, live API keys, private user records, or proprietary databases are bundled. Local system fonts are used in the editable prototypes; the original design images remain intact.
