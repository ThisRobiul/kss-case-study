# Visual production notes

The KSS cover is an editorial illustration generated with the built-in image-generation tool. It is a visual introduction to the four product surfaces. The exact prompt is retained below for future revisions.

The new app, public-web and care-administration images are browser exports of the included HTML/CSS/JavaScript source. Their labels, sample records and layout are editable. The existing sanitized Super Admin collection is retained and identified as concepts.

## Cover prompt

Use case: ui-mockup / product case-study cover.
Create a premium wide 16:9 editorial hero image for Robiul Islam's Kahaloo Smart Seba (KSS) project case study. Four related product surfaces: Android mobile app, public web services directory, Super Admin, hospital/doctor/staff administration.
Reference image 1 is an existing public mobile app screenshot, use only its white/emerald service icon palette and community-service character. Reference image 2 is a sanitized Super Admin concept, use only its refined dark navy / emerald visual language. These are reference inputs, not edit targets.
Composition: sophisticated enterprise product-design presentation, deep midnight green background, restrained emerald light, elegant editorial typography. Left upper area strong large title, lower/right area an artistic arrangement of ONE upright Android phone with a bright service-category UI, TWO desktop browser frames with precise abstract card/table layouts (one dark admin, one light public services), and ONE smaller dark clinic serial board. The four devices must feel like one designed platform, well-spaced, crisp, with subtle depth and realistic shadows. No excessive neon, no landscape photographs, no people, no fake hospital buildings. Present interface content as clean abstract UI components rather than legible invented patient records, metrics, ratings, emergency numbers or charts. Do not invent any security badge or user/revenue figures.
Exact large text only:
"Kahaloo Smart Seba"
"Local services. Connected."
Small supporting text:
"ANDROID • WEB • ADMINISTRATION"
"Product case study by Robiul Islam"
Four concise surface labels near device group, readable:
"Android app"
"Public web"
"Super Admin"
"Care administration"
Very small tasteful footer:
"Interface design showcase"
Typography: elegant modern sans-serif, off-white with mint accents, disciplined hierarchy, spacious composition, premium software product launch image suitable for the first image in a GitHub case study. Preserve the identity Kahaloo Smart Seba, never rename it Sobayan. Use a simple KSS wordmark with an original small emerald leaf accent. Large final raster, clean horizontal composition.
